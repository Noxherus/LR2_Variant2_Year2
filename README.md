## Описание

Программа реализует задания трёх уровней сложности:

- Базовый уровень: шаблонная функция `min` и анализ сложности примеров алгоритмов.
- Средний уровень: шаблонный класс `Triple<T1, T2, T3>` и сравнение линейного и бинарного поиска.
- Продвинутый уровень: шаблонный контейнер `List<T>` на основе двусвязного списка.

## Реализованные возможности

- Работа с разными типами данных.
- Методы `push_front`, `push_back`, `pop_front`, `pop_back`, `size`, `insert`, `erase`.
- Копирование и перемещение списков.
- Проверка пустого списка и недопустимых индексов.
- Анализ временной и пространственной сложности.
- Сравнение производительности `List<T>` и `std::list`.

## Сложность операций списка

| Операция | Сложность |
| --- | --- |
| push_front, push_back | O(1) |
| pop_front, pop_back | O(1) |
| size | O(1) |
| insert, erase по индексу | O(n) в худшем случае, O(1) на концах |
| Дополнительная память для хранения списка | O(n) |

Оценки времени предполагают постоянную стоимость операций с элементами.

## Среда разработки

- Язык программирования: C++17
- IDE: Microsoft Visual Studio
- Для измерения времени рекомендуется режим Release, x64.

Скомпилируйте файл `Lab2_Variant2_Year2.cpp` и запустите программу. Тесты и измерения выполняются автоматически. Для каждого измерения используется медиана трёх запусков. Время выводится в микросекундах и зависит от компьютера и параметров сборки.
